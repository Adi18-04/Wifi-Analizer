# WiFi Analyzer

A simple browser-based internet speed tester built with **HTML, CSS, and JavaScript**.

https://adi18-04.github.io/Wifi-Analizer/

### Features

* Download speed test
* Upload speed test
* 10-second tests
* Live speed display
* Online/offline status
* Responsive design

### Run Locally

Clone the repository and open `index.html`, or use a local server such as VS Code Live Server.
